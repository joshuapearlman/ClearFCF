# ClearFCF 1.2.0

ClearFCF 1.2.0 makes screening and follow-up research easier to resume, review, and move between the website and Mac app.

## Highlights

- Recoverable scans save progress, distinguish completed and unresolved companies, and retry transient failures.
- Quote freshness follows U.S. market holidays and early closes and distinguishes delayed, stale, and missing quotes.
- Named watchlists save company notes and review status. Manual rescreens show changes and trigger configured price, valuation, status, or financial-period alerts.
- Compare two to five companies using the same screening criteria and lookback.
- Export and import a versioned workspace backup with scans, watchlists, research, DCF cases, and personal WACC defaults.
- Financial Deep Analysis records dated WACC inputs, requires review before saving or exporting valuations, and supports JSON and PDF export.

## Mac app

The private Mac build includes separate Apple Silicon and Intel DMGs. The build command keeps them on the local computer. It does not publish to GitHub or require Apple Developer credentials. Saved work uses a stable local address across launches; update the app manually with a new DMG and keep a workspace backup if you want an extra copy.

International exchange screening remains a future pilot. The current screening evidence and qualification model covers U.S. equities.
