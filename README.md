# ClearFCF

**Current application version: 1.1.1**

Transparent normalized free-cash-flow screening using SEC filing evidence and current market pricing. The production source remains in [`v1.0.0`](v1.0.0) because that is the stable root-directory path configured in Vercel; the directory name is no longer the application version. Its `package.json`, website, and Mac app source are all version 1.1.1.

See [v1.0.0/README.md](v1.0.0/README.md) for setup, methodology, and release instructions.
